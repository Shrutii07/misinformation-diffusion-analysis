# Misinformation Diffusion on Social Media: A Network and Text Analysis

## Overview
This project investigates the structural and temporal differences between the spread of misinformation ("fake news") and factual news on social media. By analyzing over **2 million tweet events** and **23,000 news articles** from the [FakeNewsNet](https://github.com/kaidmml/fakenewsnet) dataset, we provide empirical evidence of how misinformation thrives in segregated "echo chambers" and exhibits unique diffusion dynamics.
